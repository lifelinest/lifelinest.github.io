  • 如果你发现你界面中某个元素需要说明，你需要重新设计
  • 简化意味着去掉不必要的元素，让必要元素凸显
  • 天才就是将复杂问题简单化的人
  • 不用盯着空白太久，勇敢的跨出第一步，其他的自然而然就会发生

    博客建站与前端人工智能博客搭建运维部署Lifeline2026-10-232026-10-23

    以前做外贸独立站，通常要找人开发，或者自己装 WordPress、配主题和插件。现在用 AI 编程代理，可以直接用中文描述需求，看着页面提修改意见，把站一点点做出来。

    这篇文章以外贸独立站为例，直接让 AI 编程代理做出首页、产品、关于和联系方式几个栏目。模板用 Envato Elements，域名注册和网站托管都放在 Cloudflare 上。

    先说句大实话：AI 代理不是魔法。它擅长改已有模板、照截图从零做页面、跑命令和部署；但完整的产品库、询盘系统、在线支付这些，仍要专业栈或后续扩展。下面把能做的和做不了的都讲清楚。

    先选路线：两种建站方式怎么选

    开始之前，先判断你要的是哪一种，避免做到一半发现路线不对。

    • 路线 A：模板 + Vite + Cloudflare。适合品牌展示站、产品落地页、轻量独立站。页面做好后上传到 Cloudflare，省去租服务器、装系统的过程。会员、支付、内容管理后台留作后续扩展。本文走的就是这个。
    • 路线 B：Hexo / WordPress / WooCommerce。适合内容型站点、电商型独立站，需要 CMS、产品库、询盘和支付。我自己的博客就是 Hexo 这套，内容管理和 SEO 更顺手，但上手比路线 A 重。

    如果你现在只是想先有个能对外展示的品牌站、落地页，路线 A 最快；后面要做询盘转化、产品目录，再迁移或扩展。下面以路线 A 完整演示。

    一、准备工作

    这次采用静态网站方案，适合个人主页、作品集和文章展示。页面制作好后上传到 Cloudflare，省去租服务器、安装系统的过程。

    1. 装好 AI 编程代理

    以 Codex 为例：通过 OpenAI 官方入口安装客户端，登录有 Codex 使用权限的账户。Codex 能打开本地文件夹、执行命令。

    使用整合后的 ChatGPT 桌面应用，在左上角切换到 Codex 即可。2026 年起 Codex 已阶段性纳入 ChatGPT Free 和 Go 套餐，Plus、Pro、Business、Edu 额度更高——也就是说不完全是付费专属，新手也能先试试。

    除了 Codex，ChatGPT、Cursor、Claude 这类能读写本地文件、跑命令的编程代理都能走同一套流程，下面统一叫「AI 代理」。

    2. 安装 Node.js

    网站在电脑上预览、生成上线文件，都要用到开发工具。这里先装 Node.js，它附带的 npm 负责下载项目需要的软件包。

    打开 Node.js 官网，选 LTS 长期支持版，下载对应系统的安装包并完成安装。

    Windows 打开「命令提示符」，Mac 打开「终端」，分别执行：

    后面用的 Wrangler 部署工具支持 Windows 11、macOS 13.5 及以上等环境。

    3. 准备 Cloudflare 账户和网站资料

    推荐用 Cloudflare 买域名、托管网站。网站采用 Cloudflare 的静态文件托管，免费档每天 10 万次请求，个人品牌站和轻量独立站基本够用；超出按量计费，单价很低。后续加动态功能时，再按所用服务核算费用。

    另外，整理好建站的素材和资料。网站参考模板推荐去 Envato 上看看。找到满意的模板后，复制网站模板 ID，可到某宝上以非常低的价格获得正版使用。或者直接参考我找到的一些模板，网址如下：

    • Cloudflare：cloudflare.com
    • Envato：elements.envato.com
    • 免费网站模板：https://pan.quark.cn/s/dbf13e77e6fb

    二、在 Cloudflare 注册域名

    打开 Cloudflare 控制台，登录并完成邮箱验证，接着注册域名：

    1. 进入 Domain Registration → Register Domains（域名注册）。
    2. 搜索想注册的名称，选择可购买的域名。
    3. 点击 Purchase（购买），选择注册年限。
    4. 核对注册费用和续费安排，填联系人、地址及付款信息。
    5. 完成购买，按邮件提示完成后续验证。

    联系人资料按真实信息填，中文信息可根据表单要求转成拼音或英文。购买成功后，域名会出现在账户中。

    域名注册好后，可直接用 Cloudflare 的 DNS 服务。

    三、选择网站模板，优先找 HTML 版

    这里推荐选 HTML 模板：下载后有现成的网页、样式和脚本，适合修改后直接部署。

    打开 Envato Elements → Web Templates，可以搜索：

    • portfolio html：作品集
    • personal website html：个人网站
    • agency html：工作室、企业展示

    商品详情里的文件类型，是选购时首先要看的地方：

    模板类型包含什么使用方法
    HTML / HTML5网页、样式、脚本适合本文，交给 AI 代理修改
    React / Next.js网站项目源码AI 代理可以处理，部署方式需结合项目检查
    WordPress ThemeWordPress 主题安装到 WordPress 环境中使用
    Elementor Template KitElementor 页面套件配合 WordPress、Elementor 和所需插件使用
    Figma / PSD页面设计稿作为设计参考，再由 AI 代理编写网页

    下载 WordPress 主题后，需要另外准备 WordPress 环境。本文是搭静态网站，用 HTML 版就够了。

    挑中模板后，打开演示站，看文章列表、正文页和手机版。如果你准备长期写文章，正文的字号、行距和栏目安排也要关注，包括演示页里的照片、字体、视频，以及留言和预约功能。有的图片只用于展示，有的表单需要另外接入接收服务。

    如果你有自己的设计想法，可以给 AI 代理几张参考截图，让它从零制作。比如参考某个站点的配色和导航，文字、图片用自己的资料。

    五、让 AI 代理看资料、做页面

    打开 AI 代理，添加本地项目，选桌面的 my-website 文件夹。

    先把这段话发进对话框：

    参考这个网站的浅色背景、左侧导航和产品卡片。使用我的文字和图片，正文按中文长文重新排版。

    AI 代理能用浏览器打开参考站。访问受限就手动补首页、正文页和手机版截图；要参考动画，再提供屏幕录像。

    方案确定后，继续发这段话：

    按确认的方案，在 site 目录制作网站。页面包括：首页、产品列表和正文、关于页、联系方式。使用现有资料，缺少的信息列出来等我补充。保留原始模板，在副本上修改，沿用适用的 HTML 结构。电脑和手机分别适配，重点处理中文正文和手机菜单。联系方式先使用公开邮箱和社媒链接。请配置 npm + Vite，提供以下命令：
    npm run dev：开发预览
    npm run build：生成上线文件
    npm run preview：检查上线文件
    采用多页面静态输出，网页和所需资源统一生成到 site/dist。每篇文章能独立打开和刷新，提供 404 页面。dist 只包含准备公开的网页资源，原始资料和模板包留在外面。完成后启动预览，检查页面和链接，说明测试结果与未完成项。本轮完成本地制作，正式发布等我确认。

    Vite 负责本地预览和生成上线文件，具体配置由 AI 代理完成。后面命令都按这套项目结构执行。装依赖、启预览时，AI 代理可能申请操作权限，检查它准备执行的内容，在当前项目范围内授权即可。

    预览期间保持终端运行，结束按 Ctrl + C。AI 代理已启动预览，可以直接打开它给的链接。

    看完网页，修改意见一定要指出具体位置。比如：

    • 首页介绍区太高，缩短一些，让第一排产品卡片露出来。
    • 正文左对齐，保留目前的配色。
    • 手机上的产品标题挤成四行。调整卡片宽度和标题字号，把图片高度降一些。

    每次调整一个区域，满意后再继续往下改。

    七、生成上线文件，做最后一轮检查

    页面调好，在 site 目录的终端按 Ctrl + C 停预览，然后执行：

    build 把网页整理到 site/dist 文件夹，这步叫构建。preview 用来查看构建结果，地址通常 http://localhost:4173/，以终端显示为准。

    首页、产品等都能正常访问，就能进发布环节了。

    上线检查可以交给 AI 代理：

    请检查 site/dist 中的网站，修复以下问题：

    • 页面打不开、刷新报错、图片缺失、链接失效。
    • 示例文字、错误联系方式、手机页面溢出。
    • 浏览器脚本错误和资源加载失败。
    • 网页标题、简介和 404 页面缺失。
      确认 dist 中只有准备公开的内容，保留许可要求的署名和版权声明。联系表单如需外部服务，请说明目前是否已经接通。完成后列出检查结果，未测试的项目单独说明，等我确认后发布。

    八、把网站部署到 Cloudflare

    九、绑定自己的域名

    网站发布后，把买的域名绑上去，访客就能通过自己的网址访问。

    1. 在 Cloudflare 后台打开刚发布的网站

    npm run deploy 成功后，Cloudflare 会保存上传的网站并建立项目。进入这个项目，为网站绑域名。

    第一步：登录 Cloudflare，打开网站项目列表。左侧菜单找 Compute & AI，展开后选 Workers & Pages，列出当前账户下已建项目。

    2. 添加自定义域

    在项目页找 Custom Domains（自定义域），点 Add，输入你注册的域名（如 xxx-trading.com），按提示确认。

    如果域名也是在 Cloudflare 注册的，DNS 记录会自动配好；如果是别的注册商，按 Cloudflare 提示去原注册商把 NS 或对应记录指向 Cloudflare。

    3. 国内访问的备案现实

    这里说句实话：如果域名最终解析到国内服务器，按要求需要备案；走 Cloudflare 境外节点一般不用备案，但国内访问速度要看实际线路。我自己的博客就是走境外托管，省了备案这一步，代价是国内部分地区速度要权衡。你按目标客户所在地选方案。

    写在最后：AI 代理能干和干不了的

    这趟跑下来，一个外贸品牌站从模板到 workers.dev 上线，核心操作基本都交给 AI 代理了，人只做描述需求、看页面、提修改。

    它能干的：改模板、照截图从零做页面、跑 npm / Wrangler 命令、部署、绑域名、修 404 和图片缺失。

    它干不了的（至少现在）：完整产品库和筛选、询盘系统落库、在线支付、多语言 SEO 架构。这些要么走路线 B（Hexo / WordPress 带 CMS），要么在 Cloudflare 上继续加 Workers、D1、Formspree 这类服务扩展。

    所以这篇的定位很明确：给你一个最快把品牌站 / 落地页亮出来的方案。等你要正经收询盘、管产品，再往上加。先上线、先被看见，比纠结完美架构更重要。

    常见问题（FAQ）

    完全不会代码，真能做出来吗？
    能。AI 编程代理负责写页面、跑命令、部署，你只描述需求、看页面提修改。模板和资料准备好，剩下交给它。
    Cloudflare 托管真的免费吗？
    免费档包含每天 10 万次请求，个人品牌站和轻量独立站基本够用；超出按量计费，单价很低。
    这种站能当外贸独立站吗？
    适合品牌展示、产品落地页、轻量独立站。要完整产品库、询盘系统、支付，建议走 Hexo / WordPress 等带 CMS 的路线。
    模板从哪来，正版怎么算？
    可以用 Envato Elements 等正版市场，也有免费开源模板和网盘分享的模板；按自己情况选，注意授权范围。
    国内访问要备案吗？
    域名若解析到国内服务器需要备案；走 Cloudflare 境外节点一般不用，但国内访问速度要看实际情况。
