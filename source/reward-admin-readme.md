# 打赏管理工具使用说明

## 功能介绍

本工具为博客打赏功能提供了一个简单的管理界面，帮助你：

- 动态添加新的打赏记录
- 编辑现有打赏记录
- 删除不需要的打赏记录
- 导出符合YAML格式的数据
- 自动保存数据到浏览器本地存储

## 使用方法

1. **访问管理页面**：打开博客，访问 `/reward-admin.html` 页面

2. **添加打赏记录**：
   - 填写打赏人姓名
   - 输入打赏金额
   - 选择打赏时间（默认为当前时间）
   - 点击「添加打赏记录」按钮

3. **导出YAML数据**：
   - 添加完所有记录后，点击「导出YAML」按钮
   - 点击「复制数据」将YAML内容复制到剪贴板

4. **更新博客数据**：
   - 用复制的YAML数据替换 `source/_data/about.yml` 文件中的 `reward_list` 部分
   - 重新生成博客：`hexo clean && hexo generate`

5. **查看更新结果**：重新部署博客后，打赏名单将自动更新

## 数据说明

- 所有打赏记录会按照金额从高到低排序显示
- 数据自动保存在浏览器的本地存储中，下次访问时依然可用
- 导出的YAML格式与主题要求完全兼容

## 注意事项

- 请确保在导出数据前检查所有记录的准确性
- 如果需要重置数据，可以使用浏览器的清除缓存功能
- 打赏管理工具仅用于方便数据管理，实际打赏功能仍需通过博客的打赏按钮完成
